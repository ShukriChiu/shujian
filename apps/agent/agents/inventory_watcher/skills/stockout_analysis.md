# 缺货分析技能

按以下流程分析缺货情况并生成补货建议：

## 步骤

1. **拉取库存快照**
   - 用 `query_supabase` 查询金蝶库存和旺店通库存
   - 排除非考核仓（效期仓、不合格仓、坏品仓）

2. **计算销售速率**
   - 查询近 30 天销售数据，按 SKU 计算日均销量
   - 区分渠道：批发 vs 电商 vs 即时零售

3. **识别缺货风险**
   - 可用库存 / 日均销量 < 7 天 → 紧急缺货
   - 可用库存 / 日均销量 < 14 天 → 预警
   - 自有品牌和包销品种加权提升优先级

4. **生成补货建议**
   - 建议补货量 = 日均销量 × 安全天数(30) - 当前库存
   - 标注供应商和最近采购价（从 ods_kingdee_purchase_order）

5. **输出报告**
   写入 `workspace/stockout_report_YYYYMMDD.md`
