# 文档分类技能

按以下流程对新文档进行分类：

## 步骤

1. **获取文档内容**
   - 如果是图片/PDF：调用 OCR 服务 `http_fetch POST {union_agent_url}/api/ocr`
   - 如果是文本文件：直接 `read_file` 读取

2. **判断证照类型**
   - 医疗器械注册证（含"注册证编号"、"国械注准/注进/注许"）
   - 备案凭证（含"备案号"、"备案凭证"）
   - 生产许可证（含"生产许可证编号"）
   - 营业执照（含"统一社会信用代码"）
   - 检验报告（含"检验报告"、"检测报告"）
   - 保健食品注册/备案（含"国食健注/备"）
   - 商标注册证（含"商标注册证"、"注册号"）

3. **提取关键字段**
   根据证照类型提取对应字段（见 soul.md 中的字段定义）

4. **关联商品/供应商**
   用 `query_supabase` 查询可能关联的商品或供应商

5. **写入结果**
   将分类结果以 JSON 格式写入 `workspace/classification_results/` 目录

## 输出格式

```json
{
  "filename": "原始文件名",
  "cert_type": "证照类型",
  "fields": { ... },
  "matched_products": [...],
  "matched_suppliers": [...],
  "warnings": ["到期预警等"],
  "classified_at": "2026-03-21T10:00:00"
}
```
